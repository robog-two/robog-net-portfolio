# examples/

Curated exemplars that show the voice and style rules in practice. Use these to
*interpret* the rules in [../VOICE.md](../VOICE.md) and [../STYLE.md](../STYLE.md) — they
are **directional and non-reusable**. Do not copy their phrasing into new posts.

The calibration set (published, live in `../../src/blog/`):

- **`human-app-ai-world.md`** — keynote adaptation. Rhetorical-question pivots, anaphora
  at the peaks, challenge-the-premise argument, explicit AI-assistance disclosure.
- **`i-wrote-a-fan-controller.md`** — technical write-up. What-it-should-do → why-build-it
  → how-it-works → link the repo. Numbered steps and a diagram over prose.
- **`learning-to-draw.md`** — personal essay. Concrete confessional open, honest and
  blunt (the deliberate swear + the footnote that flags it), explicit "Moral of the
  story" landing.
- **`first-ever-blog-post.md`** — the mission statement for the blog itself: interesting
  and new over exhaustively researched; publish over perfect; *"Posted. Boom."*

Add new exemplars here as full files when a post nails a move worth keeping.
